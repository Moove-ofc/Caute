# CAUTÊ – Centro de Estética

Site de apresentação (mobile first) do centro de estética CAUTÊ, em Torres/RS.

- `index.html`: site completo (HTML, CSS e JS; a foto do topo já está embutida no arquivo)
- `.nojekyll`: faz o GitHub Pages publicar o arquivo como está

Antes de publicar, troque o número do WhatsApp na variável `WA` no final do `index.html`.
